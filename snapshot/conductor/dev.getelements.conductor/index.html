JobScope

interface JobScope

Marker interface for job scoping hints supplied in a JobRequest. Each implementation corresponds to a ScopeType and carries the data required by the orchestration backend to honour that scope. Backends without an equivalent concept (e.g. EdgeGap, where scoping is already fully determined by the app/version identified by the JobProfile) silently ignore JobScope entirely.
