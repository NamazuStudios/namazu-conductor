EcsAttributes

object EcsAttributes

Attribute name constants for the ECS Element. Each constant is the fully-qualified attribute key used by the Elements SDK to bind configuration values via com.google.inject.name.Named injection. Default values are declared on each constant via @ElementDefaultAttribute.

const val STDIO_BRIDGE_PORT: String

Port on which a namazu-stdio-bridge sidecar (if included in the task definition's container image) listens for stdio WebSocket connections. ECS has no native container stdio API, so dev.getelements.conductor.ecs.service.EcsOrchestrationService.streamStdio depends on this bridge; declare this port in the container's port mappings for it to be reachable.
