KubernetesOrchestrationService

class KubernetesOrchestrationService(namespace: String, jobSet: String, pollInterval: String, client: <Error class: unknown class>, executor: ExecutorService) : OrchestrationService

OrchestrationService implementation backed by Kubernetes via the Fabric8 client.

Profiles correspond to PodTemplate resources in the configured namespace, filtered by the namazu.conductor/job-set label. A JobRequest is dispatched either as a bare Pod (long-standing workloads) or a batch/v1 Job (one-off, run-to-completion workloads), selected by the namazu.conductor/workload-kind annotation on the template. A Service is created only when the template declares the namazu.conductor/expose-ports annotation; its type defaults to NodePort and may be overridden via namazu.conductor/service-type.

Only RegionPlacement is honoured (mapped to a topology.kubernetes.io/zone node selector); other dev.getelements.conductor.JobPlacement types are silently ignored.

Configuration is provided by the Elements SDK via the attribute keys declared in KubernetesAttributes.

open override fun execute(request: JobRequest): JobExecution

Creates a Pod or Job for the given JobRequest and returns a JobExecution with status JobStatus.PENDING. The workload's name is derived from the profile name plus a short unique suffix and is carried in the JobExecution.id as "$namespace:$kind:$name". When the profile declares ports to expose, a Service selecting the workload is created alongside it.
