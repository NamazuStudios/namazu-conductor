OrchestrationService

interface OrchestrationService

Orchestrates container executions in the cloud. Implementations of this interface are responsible for dispatching dev.getelements.conductor.JobRequests to an underlying container platform and returning a dev.getelements.conductor.JobExecution that represents the running workload.
