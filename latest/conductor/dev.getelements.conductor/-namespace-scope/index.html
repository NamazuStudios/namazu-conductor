NamespaceScope

data class NamespaceScope(val namespace: String) : JobScope

Scopes the job to the given Kubernetes namespace, overriding the provider's configured default namespace for the created workload (and its Service, if any). The PodTemplate backing the profile is still resolved from its own namespace — this only affects where the running workload is created.
